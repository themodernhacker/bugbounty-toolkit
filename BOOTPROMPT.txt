=== STEP 2 — BURP MCP (my Burp Suite, 27 tools) ===
Host = 172.17.0.1:9876 (Docker gateway; NOT 127.0.0.1 - fails in container).
Handshake: header `Host: localhost:9876` (else 403) + `Origin: http://localhost:9876`.
GET / -> SSE `endpoint` event with `sessionId`; then POST /?sessionId=<id>.
Client: python3 /work/kit/burp_client.py <tool> [json_args]
    python3 /work/kit/burp_client.py tools/list
    python3 /work/kit/burp_client.py initialize
Gotchas: encoding helpers take key `content`; HTTP/2 tools use `pseudoHeaders`+
`headers`+`requestBody` with :method/:path/:scheme/:authority; collaborator
`customData` max 16 alphanumeric chars. Use Repeater + Scanner + Collaborator
for manual verification and OOB (SSRF/blind) confirmation.

=== STEP 6 — HOW TO WORK ===

2. Recon chain: subfinder+assetfinder+amass+crt.name -> httpx (live probe) ->
